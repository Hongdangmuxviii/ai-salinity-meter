# 하드웨어 제작 자료

현재 제작 기준은 **R5**입니다. 이전 회로·조립 전달본은 현재 파일 목록에서 폐기했습니다.

- [구매·제공 부품표](../parts/R5/)

기판은 SMEBGD1010, 홀1.2mm/피치2.54mm/두께1.6mm이며 50.80×91.44mm로 재단합니다. 전기 연결과 XIAO GPIO 배정은 유지하고 부품·커넥터 위치를 조정했습니다. 지정 외형·좌표·NET 검사를 실제 통전·충전·USB 삽입 검사로 간주하지 않습니다.

기존 헤드 CAD는 [프로젝트 모델 폴더](../project-workspace/outputs/probe_capped_head_v2/)를 사용합니다. 최종 외함 생산용 CAD는 확정되지 않았습니다.
