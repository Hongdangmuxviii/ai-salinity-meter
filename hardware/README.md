# R7 MVP 하드웨어
현재 회로·배선은 R7만 사용합니다. [회로도](schematics/R7), [만능기판](perfboard/R7), [커넥터 결선](harness/R7), [자료 검사](validation/R7).
71개 전선/99패드, D10 NC. R17/R18/C4/TP8 미실장, GJ1/GJ2 GND 접속 유지. Sense 확장보드 무개조/SD 미사용/부팅 부저 허용. 내장 USB-C 충전 유지. 실물 통전·충전·외함 삽입은 아직 미실시입니다.

배선/좌표/부품값은 R7 유지, 펌웨어·조립 보완 R7.1. D9 초기화는 pinMode→digitalWrite 순서입니다.
