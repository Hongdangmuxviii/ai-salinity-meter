부품면 그림과 납땜면 그림을 혼동하지 않습니다. 납땜면은 왼쪽19열/오른쪽1열입니다. 이전 ASM-R3/R4-P2 자료와 핀 좌표·부품표를 섞지 않습니다.

현재 [펌웨어](../firmware/SalinityMeterCalibrated/)는 USB m/k/t/p 측정 시험용입니다. OLED·버튼·부저·ToF·Wi-Fi 기능 통합은 후속 개발이며 결선 불량과 구분합니다.

실물 A0 이상 점검, 배터리 보호회로·극성·충전, 닫힌 외함에서 내장 USB-C 완전 삽입·업로드 검사는 조립업체가 실제 결과를 기록합니다. 최종 외함 CAD는 이 저장소에서 아직 확정된 상태가 아닙니다.


추가 필수 검사: Sense 확장보드 SD 풀업 분리, D9 동작에 따른 D10 배터리 감시 간섭, 모듈 양끝 접속 및 외부 Pololu 조작 접근. 주기판의 동명 R4/R5/R6와 온도 J3는 유지합니다.
