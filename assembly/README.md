Sense 저항/J3 제거·절단 금지. D10미연결/배터리표시없음/부팅부저허용. 헤드 SM2+SM4와 NW 공장압착완성선의 자유단만 단축·납땜·절연합니다. 사용자에게 압착 작업을 요구하지 않습니다.
부품은 사용자 제공. OLED/버튼 전면프레임 및 최종 외함은 실측 제작 대상이며, USB-C는 외함 닫힘 상태에서 직접 삽입·충전·업로드 검사합니다. 실제 검사 결과는 아직 없습니다.

R7.1 보완: NW 완성선은 가공 전 제공 헤더와 실제 결착·잠금·각심 도통 확인. DS18B20 수축튜브 내부4.7kΩ 풀업·이음부는 보존하고 바깥 여유선에서 SM4 연결. 새 R7.1 바이너리 빌드 완료, 기기 업로드/실물 검사는 아직 미실시.
