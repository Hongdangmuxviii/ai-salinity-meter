# 구매·제공 부품

현재 기준은 [R6 부품표](R6/BOM_R6.csv)입니다. 부품은 사용자가 구매하여 제공하고 조립업체는 재단·납땜·압착·절연·고정·검사를 수행합니다.

NW 기판 커넥터는 4P6쌍/3P3쌍/2P3쌍, 전용 단자39개 필요(구매50개)입니다. 헤드 커넥터는 연호 SMH250-05/YST025 및 SMP250-05/SMT025 한 쌍이며 5가닥 모두 AWG24입니다.

TP는 별도 부품을 구매하지 않고 지정 검사 패드를 사용합니다. 고정물·전면 프레임·케이블 길이는 실제 모듈과 외함에 맞춰 대조합니다. 링크는 상품 식별용이며 국내 실재고나 당일 출고를 보증하지 않습니다.


소모품7종(CH254 암짝선/SH 케이블/수헤더/M2·M3 고정키트/케이블타이/마운트)을 추가했습니다. ADS I2C는 P2 보조 헤더를 사용하여 별도 Gravity 케이블은 필요하지 않습니다. 외함·전면 프레임은 실측 가공 대상입니다.
